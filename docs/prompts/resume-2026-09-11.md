## The failure this codebase keeps paying for

**A guard that does not cover its class.** Six documented instances, several found *in the message
that named the pattern*:

- `docs/reviews/*-raw.md` — an ignore rule added after a real near-miss that matched **zero files in
  all history**.
- Cosmos `IS_DEFINED(c.kyc.panHash)` — true for a **present-but-null** property, so a PAN-*rejected*
  technician would have been admitted as verified.
- A mask guard test matching only `function maskPhone` / `const maskPhone =` — `let`, arrow and
  class-method forms walk past.
- Two Semgrep rules matching value-position identifiers but not type positions or object keys.
- `docs-ship.yml` — created *specifically* so docs-only PRs could satisfy branch protection, with a
  filter that left root-level config stalling one gap over from its own fix.
- `PRIMARY_NAV_HIDDEN` — §1.2. A mechanism built for a case, documenting that case, holding nothing.

**After writing any guard, run it against a realistic failing input.** `git check-ignore -v`, an
actual null-valued document, an actual alternate declaration. A guard written in response to a real
near-miss is when it feels most trustworthy and gets tested least.

Three close relatives, each with its own memory file:

- **A check that triggers on itself proves nothing.** A workflow listing its own filename in `paths:`
  goes green on the PR editing it regardless of whether the change works.
- **A mock that models an idealised dependency hides production defects behind a green suite.** Cosmos
  aggregate pages return `resources: undefined`, not `[]` (a prod 500 behind 1,935 passing tests).
  Mocking `next-intl` means no unit test can prove a message key exists.
- **A per-task check weaker than the gate it anticipates gives false confidence for a whole run.**
  `api/tsconfig.json` includes only `src/**`; `tsconfig.tests.json` adds `tests/**`. The smoke gate
  has always used the tests project — so 19 tasks of green `tsc -p .` meant less than they appeared
  to. In `api/`, always pass `-p tsconfig.tests.json`.

**And: read the diff's file manifest, not only its code.** Two reviewers, a pre-push hook and CI all
passed 2.58 MiB of transcript into `main` because each was checking whether the code in the diff was
*right*. Nobody owned the question *should this path be in the repo at all*. Run `git diff --stat`
before pushing.
