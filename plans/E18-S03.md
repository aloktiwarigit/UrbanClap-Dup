### WS-B: ADR-0021

File: `docs/adr/0021-rating-shield-threshold.md`

Write ADR following the project TEMPLATE.md format:
- **Context**: low-rating interception shield fires when user rates ≤N stars. Default shipped as ≤2★.
- **Decision**: keep threshold at ≤2★ (narrow shield). Do not widen to ≤3★ without PostHog evidence
  of >10% of bookings hitting the shield at soft-launch.
- **Consequences**: pos = minimal friction for majority of raters; neg = ≤3★ raters get no shield
  nudge; neutral = threshold is a Firebase Remote Config key so it can be changed without a release.
- **Alternatives**: ≤3★ (rejected — too broad pre-launch data), ≤1★ (rejected — 1-star is
  intentional, no shield needed).
