```kotlin

suspend fun reopenComplaint(@Path("id") id: String): ComplaintResponseDto

@GET("v1/complaints")
suspend fun getComplaints(
    @Query("page") page: Int = 1,
    @Query("limit") limit: Int = 20,

## WS-C: Compose UI

### C1. `CountdownChip.kt` — new file at `ui/components/CountdownChip.kt`
- Standalone composable accepting `deadlineIso: String?`
- Parses ISO-8601 to `Instant`, computes `secondsRemaining = deadline - now`
- `LaunchedEffect(deadlineIso)` loop: collect tick every 1s with `delay(1_000L)`
- Formats as `HH:MM:SS remaining` (EN), `HH:MM:SS शेष` (HI via string resource)
- Shows nothing if `deadlineIso` is null or deadline already passed

### C2. `ComplaintScreen.kt` — extend `SuccessState`
- When `state.isAcknowledged && state.acknowledgeDeadlineAt != null` → show `CountdownChip`
- When `state.isResolved` → show "Reopen" `HsSecondaryButton`
- `onReopen` callback added to `SuccessState`; `ComplaintContent` plumbed through

### C3. `ComplaintListScreen.kt` — new file at `ui/complaint/ComplaintListScreen.kt`
- Consumes `ComplaintListViewModel`
- Shows `LazyColumn` of complaint cards: serviceType label, status `SurfaceChip` (color-coded), `createdAt` date
- Status chip colors: OPEN → orange, ACKNOWLEDGED → blue, RESOLVED → green, REOPENED → amber
- Empty state: illustration + "No complaints yet" copy
- Each row `onClick` → `onComplaintClick(dto.id, dto.bookingId)`

### C4. Routes update — `ComplaintRoutes.kt`
Add:

```

### C5. Navigation wiring
