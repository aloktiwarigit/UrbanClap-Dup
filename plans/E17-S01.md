## Architecture overview

### Current state

`GET /v1/bookings/{id}` (`bookings.ts:509-524`) returns a thin projection:
`bookingId, status, amount, finalAmount, pendingAddOns, approvedAddOns`. The `booking.photos` field (a `Record<string, string[]>` of stage → storage-path array) is read from Cosmos but never projected to the caller.

### Target state

1. **Photos projection** — for each key in `booking.photos`, call `getStorageDownloadUrl` with a **5-minute TTL** (300 s) for every storage path, filter out null/failed URLs, and return:

   ```json
   {
     "photos": {
       "EN_ROUTE":    { "urls": ["https://…?Expires=…"] },
       "REACHED":     { "urls": ["https://…"] },
       "IN_PROGRESS": { "urls": ["https://…"] },
       "COMPLETED":   { "urls": ["https://…"] }
     }
   }
   ```

   Stages with zero resolvable URLs are omitted from the map entirely. Stage order matches the canonical `PHOTO_STAGE_ORDER` constant (`['EN_ROUTE', 'REACHED', 'IN_PROGRESS', 'COMPLETED']`).

2. **Report signed URL** — if `booking.status === 'COMPLETED'` and the PDF exists at `reports/{bookingId}.pdf`, return `reportSignedUrl: string`. Otherwise return `reportSignedUrl: null`. PDF existence is checked via `checkStorageFileExists` (already in `firebase/admin.ts`). Use 5-min TTL here too.

3. **Parallel URL generation** — sign all photo URLs and the report check concurrently (`Promise.all`) to keep latency flat.

4. **Authorization** — unchanged. Customer owns the booking (`booking.customerId === customer.customerId`). Technician read access is not required by this story (E17-S03 covers the tracking screen's caller; bookings handler stays customer-only).

## Security invariants

- **Caller must be the booking owner.** The existing `requireCustomer` middleware + `customerId` equality check (line 512-513) already enforces this. No new authz required.
- **Signed URL TTL = 5 minutes (300 s)** for both photo URLs and report URL on this endpoint. The 15-min default in `getStorageDownloadUrl` is NOT used here.
- **No PII in logs.** Signed URL strings contain the Storage object path and a time-bounded signature; they must never be passed to `Sentry.captureException` or `console.error` as structured fields. Sentry breadcrumbs from this handler must redact URL values (replace with `[redacted-signed-url]`).
- **Failed URL generation is non-fatal.** A `getSignedUrl` failure for one photo should not fail the entire GET; filter and continue. Log the storage path (not the signed URL) at `warn` level with Sentry capture.
- **Report existence check before signing.** Never generate a signed URL for a non-existent PDF; the URL would 404 and leak a valid token.

**B2 — Photo projection helper (file-scoped, not exported)**

```typescript
const PHOTO_STAGE_ORDER = ['EN_ROUTE', 'REACHED', 'IN_PROGRESS', 'COMPLETED'] as const;
const REPORT_SIGNED_URL_TTL_SECONDS = 300;
const PHOTO_SIGNED_URL_TTL_SECONDS = 300;

async function projectPhotos(
  rawPhotos: Record<string, string[]> | undefined,
): Promise<Record<string, { urls: string[] }> | undefined> {
  if (!rawPhotos || Object.keys(rawPhotos).length === 0) return undefined;

  const orderedStages = [
    ...PHOTO_STAGE_ORDER.filter((s) => rawPhotos[s]?.length),
    ...Object.keys(rawPhotos).filter((s) => !PHOTO_STAGE_ORDER.includes(s as typeof PHOTO_STAGE_ORDER[number])),
  ];

  const stageSets = await Promise.all(
    orderedStages.map(async (stage) => {
      const paths = rawPhotos[stage] ?? [];
      const urls = (
        await Promise.all(
          paths.map(async (path) => {
            try {
              return await getStorageDownloadUrlWithTtl(path, PHOTO_SIGNED_URL_TTL_SECONDS);
            } catch (err) {
              Sentry.captureException(err);
              console.warn('[getBooking] photo sign failed', { stage, path });
              return null;
            }
          }),
        )
      ).filter((u): u is string => u !== null);
      return urls.length > 0 ? ([stage, { urls }] as const) : null;
    }),
  );

  const result = Object.fromEntries(stageSets.filter((s): s is NonNullable<typeof s> => s !== null));
  return Object.keys(result).length > 0 ? result : undefined;
}
```

**B3 — Report signed URL helper (file-scoped)**

```typescript
async function projectReportSignedUrl(bookingId: string, status: string): Promise<string | null> {
  if (status !== 'COMPLETED') return null;
  const reportPath = `reports/${bookingId}.pdf`;
  try {
    const exists = await checkStorageFileExists(reportPath);
    if (!exists) return null;
    return await getStorageDownloadUrlWithTtl(reportPath, REPORT_SIGNED_URL_TTL_SECONDS);
  } catch (err) {
    Sentry.captureException(err);
    console.warn('[getBooking] report sign failed', { bookingId });
    return null;
  }
}
```

**B4 — Updated handler body**

```typescript
const getBookingInner: CustomerHttpHandler = async (req, _ctx, customer) => {
  const id = (req as unknown as { params: { id: string } }).params.id;
  const booking = await bookingRepo.getById(id);
  if (!booking) return { status: 404, jsonBody: { code: 'BOOKING_NOT_FOUND' } };
  if (booking.customerId !== customer.customerId) return { status: 403, jsonBody: { code: 'FORBIDDEN' } };

  const [photos, reportSignedUrl] = await Promise.all([
    projectPhotos(booking.photos),
    projectReportSignedUrl(id, booking.status),
  ]);

  return {
    status: 200,
    jsonBody: {
      bookingId: booking.id,
      status: booking.status,
      amount: booking.amount,
      finalAmount: booking.finalAmount ?? null,
      pendingAddOns: booking.pendingAddOns ?? [],
      approvedAddOns: booking.approvedAddOns ?? [],
      ...(photos !== undefined ? { photos } : {}),
      reportSignedUrl,
    },
  };
};
```

### WS-C: `firebase/admin.ts` — add `ttlSeconds` parameter

**C1 — Current state**

`getStorageDownloadUrl` hard-codes `15 * 60 * 1000` ms (900 s). I-A4 threat row calls this out.

**C2 — Change**

Rename the existing function to add a `ttlSeconds` parameter with a back-compat default:

```typescript
export async function getStorageDownloadUrl(storagePath: string): Promise<string> {
  return getStorageDownloadUrlWithTtl(storagePath, 900); // back-compat: 15 min
}

export async function getStorageDownloadUrlWithTtl(
  storagePath: string,
  ttlSeconds: number,
): Promise<string> {
  const bucket = defaultBucket();
  const file = bucket.file(storagePath);
  const [url] = await file.getSignedUrl({
    action: 'read',
    expires: Date.now() + ttlSeconds * 1000,
  });
  return url;
}
```

Existing callers (`formRecognizer.service.ts`, `orders-repository.ts`) import `getStorageDownloadUrl` and continue using 15-min TTL unchanged. The bookings handler imports `getStorageDownloadUrlWithTtl` and passes 300.

**C3 — Export check**

Both functions are exported; `checkStorageFileExists` and `uploadBufferToStorage` are already exported and unchanged.
