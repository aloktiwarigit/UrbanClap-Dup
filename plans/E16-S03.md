## WS-C — Photo-First Card Composables

### New file: `ui/catalogue/PhotoFirstCategoryCard.kt`
```
public fun PhotoFirstCategoryCard(
    category: Category,
    onClick: () -> Unit,
    modifier: Modifier = Modifier,
)
```
Design:
- Height 148dp, `RoundedCornerShape(16.dp)`
- Full-bleed `AsyncImage` from `category.imageUrl`, `ContentScale.Crop`
- Error/placeholder: existing `categoryStyle` icon tile (same logic as current `CategoryCard`)
- Bottom gradient scrim (0x000000 α 0.55) over image for text legibility
- Name + starting-price text overlaid at bottom-start (white, SemiBold)
- Press-scale animation: spring 0.96f (same as existing card)

### New file: `ui/catalogue/PhotoFirstServiceCard.kt`
```
public fun PhotoFirstServiceCard(
    service: Service,
    onClick: () -> Unit,
    modifier: Modifier = Modifier,
)
```
Design:
- Full-width card, `RoundedCornerShape(12.dp)`, hero image at top 164dp height
- `AsyncImage` from `service.imageUrl`, `ContentScale.Crop`
- Error/placeholder: `ServiceImageFallback` (initials tile, already exists in `ServiceListScreen.kt`)
- Below image: padding column with name (bold 16sp), description (2 lines, 13sp, muted), duration chip + price + book button (same as existing `ServiceCard`)
- `CardDefaults.cardElevation(defaultElevation = 2.dp)`, border `ServiceCardBorder`
