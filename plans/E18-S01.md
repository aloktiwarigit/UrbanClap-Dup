**Tier:** Feature
**Pattern refs:** `docs/patterns/paparazzi-cross-os-goldens.md`, `docs/patterns/kotlin-explicit-api-public-modifier.md`

## WS-C: UI + Navigation (test-first)

### C1 — Extend `CustomerBookingsViewModelTest`

Add test: COMPLETED booking with `ratingSubmitted=false` → state contains `ratingSubmitted=false`.
Add test: COMPLETED booking with `ratingSubmitted=true` → state contains `ratingSubmitted=true`.
(ViewModel passthrough — just verifying field survival through use-case → state.)

### C2 — `CustomerBookingsScreen.kt`

1. Add `onRateBooking: (String) -> Unit` and `onFileComplaint: (String) -> Unit` params to:
   - `CustomerBookingsScreen`
   - `CustomerBookingsContent`
2. Thread them through `BookingCard` call in `CustomerBookingsContent`.
3. Add private `fun CustomerBookingStatus.isClosedOrCompleted()` helper.
4. In `BookingCard`:
   - If `booking.status.isClosedOrCompleted()`:
     - If `!booking.ratingSubmitted`: `HsPrimaryButton("Rate Booking", onClick = onRateBooking(bookingId))`
     - `HsSecondaryButton("File Complaint", onClick = onFileComplaint(bookingId))`

### C3 — `CatalogueHomeScreen.kt`

Thread `onRateBooking` + `onFileComplaint` through:
- `CatalogueHomeContent` params
- `HomeTabs` params
- `CustomerBookingsScreen` call site

### C4 — `MainGraph.kt` `homeDestination`

Add:
```kotlin
onRateBooking = { id -> navController.navigate(RatingRoutes.route(id)) },
onFileComplaint = { id -> navController.navigate(ComplaintRoutes.route(id)) },
```
to the `CatalogueHomeScreen(...)` call.
